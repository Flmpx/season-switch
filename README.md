# Season Switch

在浏览器任意页面显示季节氛围场景的扩展插件。

## 功能介绍

### 季节氛围

在任意网页上叠加淡淡的季节氛围效果，不影响正常浏览，只为增添一份舒适感：

- **春** — 朦胧的绿色色调，飘落嫩绿的小叶子
- **夏** — 略带金黄的阳光色调，镜头炫光，少量深绿叶子
- **秋** — 淡黄色调，金黄与枯黄的叶子飘落
- **冬** — 淡白色调，球状雪花（内白外朦胧）飘落

支持 **自定义月份** 和 **跟随系统时间**，交界月份自动插值过渡（如 3 月春 0.7 + 夏 0.3，12 月冬 0.95 + 春 0.05）。

### 时间

支持清晨、上午、中午、下午、傍晚、晚上、深夜等时段氛围，也可 **自定义小时**（0-23 点）或 **跟随系统时间**。不同时段通过亮度遮罩层调节页面整体亮度：中午最亮（不降低亮度），深夜最暗（亮度降低到 0.7，仍保证可阅读）。夏季镜头炫光仅在白天（6-18 点）显示。夜间（19 点至次日 5 点）在屏幕上方 1/3 区域显示黄白色闪烁星光，0 点最多，向两端递减。

### 粒子

- **元素独立调节** — 叶子、雪花、星光三者的 **速度、大小、数目** 各自独立设置，互不干扰。
- **粒子数目** — 飘落元素（叶子、雪花）支持 微量(10/分钟) / 少量(20/分钟) / 中等(50/分钟) / 大量(120/分钟) / 自定义(10~1800 个/分钟)；星光的数目含义为**午夜峰值最大数量（个）**，而非"个/分钟"。
- **粒子大小** — 小 / 中 / 大 / 自定义(0~100%)，以当前默认尺寸为中等（50%），通过缩放系数同时改变各元素尺寸的上下界。
- **粒子速度** — 慢 / 中 / 快 / 自定义(0~100%)，仅飘落元素有效；星光为静止闪烁，无速度项（弹窗自动隐藏）。

### 自定义元素

粒子系统已完全数据驱动：新增一种氛围元素（如花瓣、雨滴、emoji）**只需在 `elements.json` 增加一条描述**，弹窗与运行期自动识别，零 TypeScript 改动。

### 显示程度

朦朦 / 浅 / 中 / 深 / 自定义(0~100%)

## 开发与构建

### 环境要求

- [Node.js](https://nodejs.org/) 18+
- npm（随 Node.js 安装）

### 快速开始

Clone 项目后，**必须先安装依赖**才能运行任何命令（否则会报 `wxt is not recognized` 错误）：

```bash
# 1. 安装依赖（只需执行一次，会自动执行 wxt prepare 生成类型声明）
npm install

# 2. 启动开发模式
npm run dev
```

### 开发模式

以 Chromium 为目标浏览器运行开发模式（自动监听文件变更并热重载）：

```bash
npm run dev
```

以 Firefox 为目标：

```bash
npm run dev:firefox
```

启动后，在浏览器中加载扩展：

- **Chrome**：打开 `chrome://extensions/`，开启"开发者模式"，点击"加载已解压的扩展程序"，选择 `.output/chrome-mv3-dev` 目录
- **Firefox**：打开 `about:debugging#/runtime/this-firefox`，点击"临时载入附加组件"，选择 `.output/firefox-mv3-dev` 目录下的 manifest 文件

### 构建生产版本

```bash
npm run build
```

构建产物位于 `.output/chrome-mv3` 目录。

### 打包发布

```bash
npm run zip
```

生成 `.zip` 文件位于 `dist/` 目录，可直接提交到 Chrome Web Store 或 Firefox Add-ons。

### 可用脚本

| 命令 | 说明 |
|------|------|
| `npm run dev` | 开发模式（Chromium） |
| `npm run dev:firefox` | 开发模式（Firefox） |
| `npm run build` | 构建生产版本 |
| `npm run build:firefox` | 构建 Firefox 版本 |
| `npm run zip` | 打包 zip |
| `npm run zip:firefox` | 打包 Firefox zip |
