# Season Switch

在浏览器任意页面显示季节氛围场景的扩展插件。

插件有两个界面：点击扩展图标打开的**设置弹窗**（日常快速调节），以及从粒子页「＋」进入的**管理页**（创建与管理自己的粒子元素）。

## 功能介绍

### 季节氛围

在任意网页上叠加淡淡的季节氛围效果，不影响正常浏览，只为增添一份舒适感：

- **春** — 朦胧的绿色色调，飘落嫩绿的小叶子
- **夏** — 略带金黄的阳光色调，镜头炫光，少量深绿叶子
- **秋** — 淡黄色调，金黄与枯黄的叶子飘落
- **冬** — 淡白色调，球状雪花（内白外朦胧）飘落

支持 **自定义月份** 和 **跟随系统时间**，交界月份自动插值过渡（如 3 月春 0.7 + 夏 0.3，12 月冬 0.95 + 春 0.05）。

### 时间

支持清晨、上午、中午、下午、傍晚、晚上、深夜等时段氛围，也可 **自定义小时**（0-24 点，允许半小时）或 **跟随系统时间**。不同时段通过亮度遮罩层调节页面整体亮度：中午最亮（不降低亮度），深夜最暗（亮度降低到 0.7，仍保证可阅读）。亮度与粒子出现时段共用同一个小数小时，所以 `23:30` 不会按 `23:00` 算。夏季镜头炫光仅在白天（6-18 点）显示。夜间（19 点至次日 5 点）在屏幕上方 1/3 区域显示黄白色闪烁星光，0 点最多，向两端递减。

### 粒子

- **元素独立调节** — 叶子、雪花、星光（以及你自己创建的元素）的 **速度、大小、数量** 各自独立设置，互不干扰。
- **数值化设置** — 三项都用真实数值表达：速度 `px/s`、大小 `px`、数量 `个/分钟`（飘落）或 `个`（闪烁）。弹窗里的「慢 / 中 / 快」「小 / 中 / 大」「微量 / 少量 / 中等 / 大量」是每个元素自带的常用值，点一下即把数值改成那一档；数值不等于任何档位时显示「自定义」，可拖滑块精确调整。
- **粒子数量** — 飘落元素 `0 ~ 360 个/分钟`（叶子、雪花的档位为 10 / 20 / 50 / 120）；星光的数量含义为**午夜峰值最大数量**，`0 ~ 300 个`（档位 15 / 30 / 60 / 120）。
- **粒子大小** — `1 ~ 120 px`；叶子档位 4 / 7 / 10，雪花 4 / 6.5 / 10，星光 1 / 2 / 3。
- **粒子速度** — `0 ~ 200 px/s`，仅飘落元素有效；星光为静止闪烁，无速度项（弹窗自动隐藏）。

### 自定义元素

popup 粒子页右上角的「＋」会打开**管理页**（独立标签页），在这里可以完整地创建自己的粒子：

- **新建粒子** — 左侧表单（基础 / 外观 / 出现 / 运动 / 档位），右侧 180×180 实时预览，粒子会按真实运动参数演示；保存后出现在「我的粒子」。
- **四种外观** — SVG 路径（可直接导入 `.svg` 文件）、图片（PNG / JPEG / WebP / GIF / SVG，按内容去重）、emoji 字形、任意文字。
- **出现区域** — 在管理页里点「框选区域」拖出一个方框（与网页窗口同比例），鼠标悬浮按钮可看到当前比例。
- **出现时段** — 一条 0–24 点的轨道上两个圆点，支持跨午夜。
- **我的粒子** — 内置粒子与自定义粒子分组列出，点进去可改出现 / 运动 / 档位（改动即时保存）；自定义元素可删除（点两次确认），内置元素可「恢复默认」。
- **内置元素受保护** — 名称、图标、行为与外观不可修改，只可调整出现、运动与档位。
- **导入 / 导出 JSON** — 导出整个自定义元素库，换台机器导入即可复用；图片资产不包含在导出的 JSON 里，需要在目标机器重新上传。

粒子系统完全数据驱动：也可以继续手写 `elements.json` 或导入 JSON，新增元素不需要改 TypeScript 代码。

### 显示程度

朦朦 / 浅 / 中 / 深 / 自定义(0~200%，100% 即「中」)

## 开发与构建

### 环境要求

- [Node.js](https://nodejs.org/) 18+
- npm（随 Node.js 安装）

### 快速开始

Clone 项目后，**必须先安装依赖**才能运行任何命令（否则会报 `wxt is not recognized` 错误）：

```bash
# 1. 安装依赖（只需执行一次，会自动执行 wxt prepare 生成类型声明）
npm install

# 2. 启动开发模式
npm run dev
```

### 开发模式

运行开发模式（自动监听文件变更并热重载）：

```bash
npm run dev
```

启动后，打开 `chrome://extensions/`，开启"开发者模式"，点击"加载已解压的扩展程序"，选择 `.output/chrome-mv3-dev` 目录。

> 改动 popup 或管理页后，需要**关掉再重新打开**对应界面才会加载新代码。

### 构建生产版本

```bash
npm run build
```

构建产物位于 `.output/chrome-mv3` 目录。

### 打包发布

```bash
npm run zip
```

生成 `.zip` 文件位于 `dist/` 目录，可直接提交到 Chrome Web Store。

### 可用脚本

| 命令 | 说明 |
|------|------|
| `npm run dev` | 开发模式 |
| `npm run build` | 构建生产版本 |
| `npm run zip` | 打包 zip |
