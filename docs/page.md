# 界面设计（Season Switch）

> 本文件描述 Season Switch 的**两个设置界面**：popup 弹窗与管理页（独立标签页）。
> 架构见 [`design.md`](./design.md)，美术与观感见 [`art.md`](./art.md)。

## 1. 两个界面与分工

| 界面 | 入口 | 定位 |
| --- | --- | --- |
| **popup 弹窗**（宽 `340px`，高自适应，上限 `600px`） | 点击扩展图标 | 高频微调：季节 / 时间 / 显示程度 / 每个元素的速度·大小·数量 |
| **管理页**（`manager.html`，独立标签页） | popup 粒子页右上角「＋」 | 造元素：新建 / 我的粒子 / 详情 / 导入导出 JSON |

分工原则：**轻量调节留在弹窗，凡是需要填名称、传图片、调抖动这类"重活"全部放到管理页**。340px 宽的弹窗里塞不下一张表单，硬塞只会让两边都难用。

「＋」的行为：已有管理页标签时**复用它**、切到该标签并跳到「新建粒子」，没有才新开一个，避免开一堆重复标签。

## 2. popup 弹窗

### 2.1 总体形态

点击插件图标弹出 popup（非独立标签页），采用 **iOS 式导航栈**：首屏是几个主选项，点选项后新页从右侧滑入、旧页面向左推出；逐层下钻，每层左上角有一个纯箭头「返回」。

- 宽度固定 `340px`，高度由当前页内容自适应（配合 `height` 过渡），上限 `600px`，超出则**页内滚动**。
- 白底卡片风格：页面底色 `#f4f5f7`，选项与滑块装在白色圆角卡片里。

### 2.2 视觉主题

| 项目 | 取值 | 说明 |
| --- | --- | --- |
| 页面底色 / 卡片 | `#f4f5f7` / `#ffffff` | 浅灰底 + 白卡片，卡片带极浅投影 |
| 正文 / 说明文字 | `#1f2328` / `#8a919b` | 深灰正文 + 中灰说明 |
| 强调色 / 浅强调底 | `#4a7bd8` / `#e8eefb` | 只用于选中态与图标底色 |
| 圆角 | 卡片 `14px` / 控件 `9px` | 卡片比控件略大 |
| 行高 / 控件高 | 卡片行 `62px`（图标 `36px` + 上下 `13px` 内边距）；选项胶囊 `32px`；「＋」按钮 `30px` | 比管理页更紧凑 |
| 图标 | `36px` 圆形浅强调底 + 线性图标 | 图标来自 `lib/icons.ts`，不是 emoji |
| 滑块 | 高 `4px` 轨道 + `16px` 圆点；右侧数值 `58px` 固定宽 | 「自定义」展开后用，常驻显示数值 |

### 2.3 页面层级

```
主页（六项卡片，右侧带 ›；前四项改效果，后两项进管理页与全局设置）
├─ 季节      春/夏/秋/冬/自定义月份/跟随系统 + 自定义月份滑块（1–12 月）
├─ 时间      清晨/上午/中午/下午/傍晚/晚上/深夜/自定义时间/跟随系统 + 自定义小时滑块（0–24 点，步长 0.5）
├─ 显示程度  朦朦/浅/中/深/自定义 + 自定义百分比滑块（0–200%，100% 即「中」）
├─ 粒子（元素列表，来自注册表，含内置与自定义；说明行显示「飘落 · 8px · 数量 50 个/分钟」）
│  └─ 单个元素
│     ├─ 速度   慢/中/快/自定义（仅飘落元素）
│     ├─ 大小   小/中/大/自定义
│     └─ 数量   微量/少量/中等/大量/自定义
├─ 我的粒子  打开管理页并直接落到「我的粒子」列表（与上方之间多留 8px 分组间距）
└─ 设置      光晕开关、亮度随时间变化开关
```

**元素页的档位规则**：

- 每根轴 = 一排档位胶囊 + 一个「自定义」胶囊；「自定义」被选中时下方展开滑块，右侧显示**真实数值与单位**。
- 选中态由数据决定：当前值来自某档（`kind: 'preset'`）→ 点亮那一档；来自自定义（`kind: 'custom'`）→ 点亮「自定义」并自动展开滑块（重新打开也保持如此）。
- 点某档 = 把值改成那一档的数值并立刻保存；拖滑块 = 值变成自定义，不需要额外确认。
- 单位：速度 `px/s`、大小 `px`、数量 `个/分钟`（飘落）或 `个`（闪烁）。
- 星光没有速度轴（弹窗自动隐藏该项），其「数量」是午夜峰值颗数。

各元素的档位数值由描述符自带，因此不同元素的"中档"可能不同：

| 元素 | 速度（慢/中/快） | 大小（小/中/大） | 数量（四档） |
| --- | --- | --- | --- |
| 叶子 | 14 / 28 / 50 px/s | 4 / 7 / 10 px | 10 / 20 / 50 / 120 个每分钟 |
| 雪花 | 10 / 20 / 36 px/s | 4 / 6.5 / 10 px | 10 / 20 / 50 / 120 个每分钟 |
| 星光 | —（无速度轴） | 1 / 2 / 3 px | 15 / 30 / 60 / 120 个 |

### 2.4 交互

- **只有悬停变色**：卡片行、选项胶囊悬停时底色略深（`#f7f9fc` / `#eff2f7`），不使用自绘光斑或点击特效。
- **开关**：设置页两行开关（光晕、亮度随时间变化），点整行即切换并立刻保存，没有保存按钮；开关由 `switchRow` 生成，`aria-checked` 同步。
- **切页与高度**：页面在 `.pages` 容器里横向平移，容器高度由 `nav.ts` 按当前页内容重算，`0.3s` 过渡，超过 `600px` 改为页内滚动。
- **滚动条**：内容超高时显示 `6px` 细滚动条，配色跟随主题（不再是默认白条）。

### 2.5 模块划分

每个页面独立成文件、各自渲染 + 绑定；公共的卡片/滑块/页壳收在 `ui.ts`。

| 文件 | 职责 |
| --- | --- |
| `popup/index.html` | 弹窗入口：`.nav-stack > .pages#pages` 容器，页面由 JS 挂载 |
| `popup/main.ts` | 入口：`registry.init()` → 加载设置 → 渲染主页 |
| `popup/nav.ts` | 导航栈：`initNav` / `pushPage` / `popPage` / `refreshHeight` |
| `popup/ui.ts` | 公共控件：`pageShell` / `cardRow` / `setRowActive` / `sliderCard` / `switchRow` |
| `popup/style.css` | 全部样式（白卡片主题、导航栈、卡片行、胶囊、滑块、开关） |
| `popup/pages/main.ts` | 主页：季节 / 时间 / 显示程度 / 粒子 / 我的粒子 / 设置 六个入口 |
| `popup/open-manager.ts` | 打开管理页：已有标签就切过去并直达指定视图，没有才新建 |
| `popup/pages/season.ts` | 季节设置页 |
| `popup/pages/time.ts` | 时间设置页 |
| `popup/pages/display.ts` | 显示程度设置页 |
| `popup/pages/settings.ts` | 全局设置页：光晕、亮度随时间变化两个开关 |
| `popup/pages/particle.ts` | 粒子元素列表；页头右侧「＋」打开管理页 |
| `popup/pages/element.ts` | 单个元素的三根轴（档位 + 自定义滑块） |

各页面只从 `lib/settings` 读写配置、从 `nav` 取导航能力、从 `envir/particle` 只读元素元数据，互不耦合。

## 3. 管理页

### 3.1 形态与布局

- **左侧固定侧边栏 `220px`**：品牌区（`Season Switch` / `粒子管理`）→ 两个导航项（`新建粒子`、`我的粒子`，各 `42px` 高，带线性图标）→ 底部说明文字。当前视图对应的导航项高亮，**详情页归属「我的粒子」**。
- **右侧内容区**独立滚动：`padding: 32px 40px 64px`。内容随窗口变宽而变宽，不设最大宽度（否则宽屏右侧会空出一大条）。
- 视图内区块间距 `22px`；表单里五个折叠分组之间再留 `18px`，避免分组连成一片。
- 新建与详情为两栏：左列自适应、右列预览固定 `300px` 并 `sticky` 吸顶（`top: 24px`）。
- 所有可点控件统一 `40px` 高、`10px` 圆角，比 popup 更松，长时间填表单不累。

### 3.2 视觉主题（管理页自带一份变量，不与 popup 共享）

| 变量 | 取值 | 用途 |
| --- | --- | --- |
| `--bg` / `--card` | `#f4f5f7` / `#ffffff` | 页面底色 / 卡片与侧边栏 |
| `--line` | `#eceff3` | 分隔线与卡片描边 |
| `--text` / `--sub` | `#1f2328` / `#8a919b` | 正文 / 说明 |
| `--accent` / `--tint` / `--accent-deep` | `#4a7bd8` / `#e8eefb` / `#31599f` | 强调 / 浅强调底 / 强调文字与悬停描边 |
| `--danger` | `#d24545` | 删除与校验错误 |
| `--radius` / `--control` | `14px` / `40px` | 圆角 / 控件高度（输入框与按钮圆角 `10px`） |
| `--ease` | `cubic-bezier(0.32, 0.72, 0, 1)` | 统一缓动 |

按钮四态：`primary`（强调底白字）、`ghost`（白底细描边）、`danger`（红字细描边）、`armed`（二次确认态，实心红底白字，悬停更深）。

### 3.3 路由

hash 路由，直接改地址即可切换、刷新后保持：

| 路由 | 视图 |
| --- | --- |
| `#/new` | 新建粒子 |
| `#/mine` | 我的粒子（默认） |
| `#/detail/<id>` | 元素详情；元素不存在时回落 `#/mine` |

### 3.4 三个视图

**新建粒子（`#/new`）**
顶栏：标题（随名称变化为「新建粒子 · 叶子」）+ 右侧「保存」。
左列表单（见 3.5），右列 `180×180` 实时预览（sticky，滚动时跟随）。
保存前校验，失败时表单上方出现红色提示条并**不写入**；成功则跳到该元素的详情页。
新建页**不即时保存**——草稿留在内存里，避免半成品混进列表。

**我的粒子（`#/mine`）**
顶栏：「我的粒子」+ 右侧「导入 JSON」「导出 JSON」「新建粒子」。
列表分两组：**内置粒子**、**自定义粒子**。每行 = 图标 + 名称 + 副标题（`飘落 · SVG`）+ 徽标（`内置` / `自定义`）+ 「编辑」；自定义元素多一个「删除」。
删除是**原地二次确认**：点一下变成「确认删除」（实心红底白字），`2.5` 秒内再点才真删，超时自动复原。分组为空时显示一句说明 + 「新建一个」。
导入策略：同 `id` 覆盖，文件里没有的旧元素保留；导入前先校验，错误只提示第一条。

**详情（`#/detail/<id>`）**
顶栏：「返回」+ 标题（跟随名称）+ 右侧「恢复默认」（仅内置元素）或「删除」（仅自定义元素）。
两列布局与新建页一致。
改动**即时保存**：输入停止 `300ms` 后落盘，右下角弹「已保存」；用户元素直接改用户库，内置元素只把"与模板不同的字段"写进 `overrides`，所以随时能点「恢复默认」回到内置值。
**内置元素的「基础」（名称、图标、行为）与「外观」都只读**，展开后只显示一句"内置元素的基础信息不可修改"/"内置外观不可修改"；可改的只有 出现 / 运动 / 档位。

### 3.5 表单结构（新建与详情共用）

五个折叠分组，顺序固定：

| 分组 | 内容 |
| --- | --- |
| **基础** | 名称、图标（图标名如 `leaf`，或一个字符）、行为（飘落 / 闪烁）；内置元素只读 |
| **外观** | 四选一：SVG / 图片 / emoji / 文字，下方切换对应编辑器；内置元素只读 |
| **出现** | 两种行为一致：季节多选、出现区域（按钮 + 悬浮说明）、出现时段（单轨两圆点）、跨午夜开关 |
| **运动**（默认折叠） | 按行为分别渲染：飘落为 抖动 / 摆动频率 / 摆幅 / 旋转速度 / 不透明度；闪烁为 抖动 / 不透明度 / 闪烁频率 |
| **档位**（默认折叠） | 飘落：速度 / 大小 / 数量三根轴；闪烁：大小 / 数量两根轴（没有速度轴） |

季节多选至少保留一个（界面不允许取消到零）；手写或导入的 JSON 里若 `seasons` 为空，该元素不会出现在任何季节。

外观编辑器：

- **SVG**：选择 `.svg` 文件，或粘贴代码后点「解析粘贴的 SVG」；下方显示解析结果（路径条数、警告，如"渐变已简化为纯色""文本元素未导入"）。
- **图片**：选择文件（≤ `512KB`），自动读出宽高比写入资产库，显示缩略图 + 可微调的宽高比滑块。
- **emoji**：一排常用字形（点一下即填入）+ 手动输入框。
- **文字**：内容、字体（雅黑 / 宋体 / 楷体 / 衬线 / 无衬线）、字重（400 / 600 / 700）、颜色。

**出现区域**：点「框选区域」在旁边弹出全窗口遮罩（见 3.7），拖出一个方框，确定后把方框相对窗口的比例写进元素的 `region`；鼠标悬浮按钮时用气泡显示当前比例（`左 0% · 上 0% · 宽 100% · 高 33%`）。

**出现时段**：一条 `0–24` 轨道上两个圆点。跨午夜 = 否时左圆点是出现时刻、右圆点是消失时刻；跨午夜 = 是时**左右含义对调**（左消失、右出现）。两点不允许互相穿过，也不允许重合（至少差 `0.5` 点）。

**所有数值字段都用滑块**，步长与区间来自 `NUMERIC_LIMITS`（例如旋转速度 `−3 ~ 3 rad/s`，步长 `0.05`，允许负值表示反向旋转），读取层另有夹取兜底。

### 3.6 自绘滑块

滑块由 `fields.ts` 的 `createTrack` 绘制（不用原生 `input[type=range]`），因为原生圆点是伪元素、无法在其上挂气泡：

- 单圆点（普通数值）与多圆点（档位、出现时段）共用一套实现；多圆点之间会互相卡位，不会穿过。
- **数值只在悬浮/拖动时显示**：气泡随圆点移动，宽度按最大值的位数固定（等宽数字），所以拖动时不会抖；静止时不显示数值，保持界面干净。
- 整条轨道可点击跳转；点中圆点本身则不会因为几像素偏移就跳动。
- 键盘：`←/→` 一个步长，`PageUp/PageDown` 十个步长，`Home/End` 到两端；带 `role="slider"` 与 `aria-valuenow`。
- 圆点悬停放大 `1.18` 倍并加深描边，没有任何光晕阴影。

### 3.7 区域框选遮罩

`region-modal.ts` 在管理页内盖一层全窗口遮罩（shadow DOM 隔离样式）：中间是 `2px` 强调色方框、八个白色手柄可拖边角、顶部面板显示「尺寸 % × %」与「取消 / 确定」。`ESC` 取消，点确定返回方框相对窗口的比例。

### 3.8 图标

界面里的图标全部来自 `lib/icons.ts` 的 21 个线性图标（`leaf`、`snow`、`sparkle`、`clock`、`sun`、`sprout`、`calendar`、`monitor`、`sunrise`、`sunset`、`moon`、`star`、`cloud`、`cloudsun`、`mist`、`level`、`plus`、`list`、`image`、`text`、`emoji`），是 `24×24` 内联 SVG（`stroke: currentColor`），颜色跟随文字，也避开了部分站点的 CSP。元素描述符里的 `icon` 既可以是图标名，也可以是一个字符（用户自己的 emoji 会原样显示）。

### 3.9 交互

- **只有悬停变色与过渡**：不使用自绘光斑或点击特效，交互反馈靠底色变化、折叠动画与气泡提示。
- **折叠动画**：分组标题点击后高度从 `0` 过渡到内容高度（`260ms`），箭头旋转 90°。不用 `<details>`，因为它无法做高度过渡。
- **气泡提示**：表单里以虚线下划线标注可解释的标签，悬停显示气泡（`data-tip` + CSS `::after`），内容随当前值变化（如出现时段、出现区域比例）。
- **轻提示**：右下角胶囊形 toast，浅色底，`2.6` 秒淡出；错误态为红底白字。
- **降级**：`prefers-reduced-motion` 下关闭过渡动画。

## 4. 两个界面的视觉一致性

同一套语言，不同密度：

| 维度 | popup | 管理页 |
| --- | --- | --- |
| 底色 / 卡片 | `#f4f5f7` / `#ffffff` | `#f4f5f7` / `#ffffff` |
| 强调色 | `#4a7bd8` + 浅底 `#e8eefb` | 同左 |
| 控件高度 | `32px`（胶囊）/ `62px`（卡片行） | `40px` |
| 圆角 | `14px` 卡片 / `9px` 控件 | `14px` 卡片 / `10px` 控件 |
