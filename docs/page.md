# 界面设计（Season Switch）

> 本文件描述 Season Switch 的**两个设置界面**：popup 弹窗与管理页（独立标签页）。
> 架构见 [`design.md`](./design.md)，美术与观感见 [`art.md`](./art.md)。

## 1. 两个界面与分工

| 界面 | 入口 | 定位 |
| --- | --- | --- |
| **popup 弹窗**（宽 `340px`，高自适应，上限 `600px`） | 点击扩展图标 | 高频微调：季节 / 时间 / 显示程度 / 每个元素的速度·大小·数目 |
| **管理页**（`manager.html`，独立标签页） | popup 粒子页右上角「＋」 | 造元素：新建 / 我的粒子 / 详情 / 导入导出 JSON |

分工原则：**轻量调节留在弹窗，凡是需要填名称、传图片、调抖动这类"重活"全部放到管理页**。340px 宽的弹窗里塞不下一张表单，硬塞只会让两边都难用。

「＋」的行为：已有管理页标签时**复用它**并切到「新建粒子」，没有才新开一个，避免开一堆重复标签。

## 2. popup 弹窗

### 2.1 总体形态

点击插件图标弹出 popup（非独立标签页），采用 **iOS 式导航栈**：首屏是几个主选项，点选项后新页从右侧滑入、旧页面向左推出；逐层下钻，每层顶部有「返回」。

- 宽度固定 `340px`，高度由当前页内容自适应（配合 `height` 过渡），上限 `600px`，超出则**页内滚动**。
- 背景 `#3c3c3c`（中深灰），文字 `#e8e8e8`。

### 2.2 视觉主题

| 项目 | 取值 | 说明 |
| --- | --- | --- |
| 弹窗背景 | `#3c3c3c` | 中深灰底 |
| 正文文字 | `#e8e8e8` | 浅灰白 |
| 选项按钮 | 高 `37px`、左右留白 `20px`、`1px solid #fff` 边框、`8px` 圆角、字号 `14px` | 与历史设定一致 |
| 选中态 | 白底 `#ffffff` + 黑字 `#161616`、字重 `600` | 点击后即刻生效 |
| hover 光斑 | `rgba(255,255,255,0.06)` 底 + `100px` 径向柔光 | 光标跟随 |
| 滑块 | 轨道 `4px` `#3a3a3a`、白色圆点 `14px`、右侧数值 `12px` | 「自定义」展开后用 |
| 页头 | 标题 `15px` 居中；「返回」`14px` 居左；「＋」`26px` 高居右 | 三者水平对齐 |

### 2.3 页面层级

```
主页（主选项，右侧带 ›）
├─ 季节      春/夏/秋/冬/自定义/跟随系统 + 自定义月份滑块
├─ 时间      清晨/上午/中午/下午/傍晚/晚上/深夜/自定义/跟随系统 + 自定义小时滑块
├─ 显示程度  朦朦/浅/中/深/自定义 + 自定义百分比滑块
└─ 粒子（元素列表，来自注册表，含内置与自定义）
   └─ 单个元素
      ├─ 速度   慢/中/快/自定义（仅飘落元素）
      ├─ 大小   小/中/大/自定义
      └─ 数目   微量/少量/中等/大量/自定义
```

**元素页的档位规则（数值化后的关键变化）**：

- 每根轴 = 一行档位按钮 + 一个「自定义」按钮；「自定义」被选中时下方展开滑块，右侧显示**真实数值与单位**。
- 当前值**恰好等于**某档 → 点亮该档；不等于任何档 → 点亮「自定义」并自动展开滑块（刷新后依然如此）。
- 点击某档 = 把值改成那一档的数值并立刻保存，不需要额外确认。
- 单位：速度 `px/s`、大小 `px`、数目 `个/分钟`（飘落）或 `个`（闪烁）。
- 星光没有速度轴（弹窗自动隐藏该项），其「数目」是午夜峰值颗数。

各元素的档位数值由描述符自带，因此不同元素的"中档"数值可能不同：

| 元素 | 速度（慢/中/快） | 大小（小/中/大） | 数目（四档） |
| --- | --- | --- | --- |
| 叶子 | 14 / 28 / 50 px/s | 4 / 7 / 10 px | 10 / 20 / 50 / 120 个每分钟 |
| 雪花 | 10 / 20 / 36 px/s | 4 / 6.5 / 10 px | 10 / 20 / 50 / 120 个每分钟 |
| 星光 | —（无速度轴） | 1 / 2 / 3 px | 15 / 30 / 60 / 120 个 |

### 2.4 交互特效

由 `popup/effects.ts` 以事件委托挂在根节点上统一处理，不侵入各页面模块。

- **hover 光斑**：`mousemove` 时把光标相对元素左上角的坐标写入 `--mx` / `--my`，CSS 用 `radial-gradient` 在该处画柔光，仅 `:hover` 时可见。作用于 `.row` / `.option-btn` / `.back`。
- **点击波纹**：仅作用于 `.option-btn`（点了**不翻页**的选项按钮）。点击后按钮**立即**白底黑字，同时从点击点生成一个灰色圆（`rgba(0,0,0,0.35)`），按按钮对角线尺寸放大扩散并淡出。`.option-btn` 用 `isolation: isolate` 建立层叠上下文，使灰色波纹落于白底之上、文字之下。
- **切页行 / 返回按钮不挂波纹**：一点即滑走，波纹根本看不到。

### 2.5 模块划分

每个页面独立成文件、各自渲染 + 绑定，不强行抽公共函数（即便代码重复）。

| 文件 | 职责 |
| --- | --- |
| `popup/index.html` | 弹窗入口：`.nav-stack > .pages#pages` 容器，页面由 JS 挂载 |
| `popup/main.ts` | 入口：`registry.init()` → 加载设置 → 渲染主页 → 启用交互特效 |
| `popup/nav.ts` | 导航栈：`initNav` / `pushPage` / `popPage` / `refreshHeight` |
| `popup/effects.ts` | 交互特效：hover 光斑 + 点击灰色波纹（事件委托） |
| `popup/style.css` | 全部样式（暗色主题、导航栈、选项、滑块、波纹） |
| `popup/pages/main.ts` | 主页：季节 / 时间 / 显示程度 / 粒子 四个入口 |
| `popup/pages/season.ts` | 季节设置页 |
| `popup/pages/time.ts` | 时间设置页 |
| `popup/pages/display.ts` | 显示程度设置页 |
| `popup/pages/particle.ts` | 粒子元素列表；页头右侧「＋」打开管理页 |
| `popup/pages/element.ts` | 单个元素的三根轴（档位 + 自定义滑块） |

各页面只从 `lib/settings` 读写配置、从 `nav` 取导航能力、从 `envir/particle` 只读元素元数据，互不耦合。

## 3. 管理页

### 3.1 形态与布局

- **左侧固定侧边栏 `208px`**：品牌区（`Season Switch` / `粒子管理`）→ 两个导航项（`＋ 新建粒子`、`☰ 我的粒子`，各 `44px` 高）→ 底部说明文字。当前视图对应的导航项高亮，**详情页归属「我的粒子」**。
- **右侧内容区**独立滚动：`padding: 40px 48px 64px`。内容随窗口变宽而变宽，不设最大宽度（否则宽屏右侧会空出一大条）。
- 视图内区块间距 `26px`；表单里五个折叠分组之间再留 `18px`，避免分组边框连成一片。
- 新建与详情为两栏：左列自适应、右列预览固定 `300px` 并 `sticky` 吸顶（`top: 40px`）；窗口过窄时两栏会互相挤压，但不做折叠。
- 所有可点控件统一 `44px` 高、`10px` 圆角，比 popup 更松，长时间填表单不累。

### 3.2 视觉主题（管理页自带一份变量，不与 popup 共享）

| 变量 | 取值 | 用途 |
| --- | --- | --- |
| `--bg` / `--bg-side` | `#2b2b2b` / `#232323` | 页面底色 / 侧边栏底色 |
| `--panel` / `--panel-2` | `#2f2f2f` / `#262626` | 分组卡片 / 次级区块 |
| `--line` / `--line-2` | `#3a3a3a` / `#4a4a4a` | 分隔线 / 控件描边 |
| `--text` / `--text-dim` / `--text-faint` | `#e8e8e8` / `#b8b8b8` / `#8a8a8a` | 正文 / 说明 / 次要提示 |
| `--radius` / `--control-h` | `10px` / `44px` | 圆角 / 控件高度 |
| `--ease` | `cubic-bezier(0.4, 0, 0.2, 1)` | 统一缓动 |

按钮三档：`primary`（浅色底 `#e8e8e8` + 深字，用于保存/新建）、`ghost`（透明底，hover 微亮）、`danger`（暗红描边 `#5c3a3a`，二次确认时变为实心红 `#7a2f2f`）。

### 3.3 路由

hash 路由，直接改地址即可切换、刷新后保持：

| 路由 | 视图 |
| --- | --- |
| `#/new` | 新建粒子 |
| `#/mine` | 我的粒子（默认） |
| `#/detail/<id>` | 元素详情；元素不存在时回落 `#/mine` |

### 3.4 三个视图

**新建粒子（`#/new`）**
顶栏：标题（随名称变化为「新建粒子 · 叶子」）+ 右侧「保存」。
左列表单（见 3.5），右列 `180×180` 实时预览（sticky，滚动时跟随）。
保存前校验，失败时表单上方出现红色提示条并**不写入**；成功则跳到该元素的详情页。
新建页**不即时保存**——草稿留在内存里，避免半成品混进列表。

**我的粒子（`#/mine`）**
顶栏：「我的粒子」+ 右侧「导入 JSON」「导出 JSON」「新建粒子」。
列表分两组：**内置粒子**、**自定义粒子**。每行 = 图标 + 名称 + 副标题（`飘落 · SVG`）+ 徽标（`内置` / `自定义`）+ 「编辑」；自定义元素多一个「删除」。
删除是**原地二次确认**：点一下变成「确认删除」并转红，`2.5` 秒内再点才真删，超时自动复原。分组为空时显示一句说明 + 「新建一个」。
导入策略：同 `id` 覆盖，文件里没有的旧元素保留；导入前先校验，错误只提示第一条。

**详情（`#/detail/<id>`）**
顶栏：「返回」+ 标题（跟随名称）+ 右侧「恢复默认」（仅内置元素）或「删除」（仅自定义元素）。
两列布局与新建页一致。
改动**即时保存**：输入停止 `300ms` 后落盘，右下角弹「已保存」；用户元素直接改用户库，内置元素只把"与模板不同的字段"写进 `overrides`，所以随时能点「恢复默认」回到内置外观与数值。
内置元素的外观区只读，显示一句"内置外观不可修改"——避免用户改完后发现删不掉、也回不到原样。

### 3.5 表单结构（新建与详情共用）

五个折叠分组，顺序固定：

| 分组 | 内容 |
| --- | --- |
| **基础** | 名称、图标（≤ 4 字）、行为（飘落 / 闪烁） |
| **外观** | 四选一：SVG / 图片 / emoji / 文字，下方切换对应编辑器 |
| **出现** | 飘落元素：季节多选（至少一项）；闪烁元素：区域（上三分之一 / 全屏）+ 起止小时 |
| **运动**（默认折叠） | 抖动、摆动频率、摆幅、旋转速度、不透明度、闪烁频率 |
| **档位与默认值**（默认折叠） | 三根轴各 3 个档位值 + 默认速度 / 大小 / 数目 |

外观编辑器：

- **SVG**：选择 `.svg` 文件，或粘贴代码后点「解析粘贴的 SVG」；下方显示解析结果（路径条数、警告，如"渐变已简化为纯色""文本元素未导入"）。
- **图片**：选择文件（≤ `512KB`），自动读出宽高比写入资产库，显示缩略图 + 可微调的宽高比滑块。
- **emoji**：一排常用字形（点一下即填入）+ 手动输入框。
- **文字**：内容、字体（雅黑 / 宋体 / 楷体 / 衬线 / 无衬线）、字重（400 / 600 / 700）、颜色。

**所有数值字段用滑块**，右侧显示真实数值与单位，步长与区间来自 `NUMERIC_LIMITS`（例如旋转速度 `−3 ~ 3 rad/s`，步长 `0.05`，允许负值表示反向旋转）。滑块的作用是让"手滑输入 99999"这类事故不可能发生；读取层另有夹取兜底。

### 3.6 交互特效

- **聚光灯**：所有可点元素（导航项、按钮、列表行、分段按钮、emoji 格子、分组标题）hover 时，光标处出现 `140px` 柔光，参数随元素类型略有差异。
- **波纹**：只给**点了不跳转**的控件——表单里的分段按钮与 emoji 格子。导航项、按钮、列表行不加波纹（理由同 popup：点了就换视图，波纹看不见）。
- **折叠动画**：分组标题点击后高度从 `0` 过渡到内容高度（`260ms`），箭头旋转 90°。不用 `<details>`，因为它无法做高度过渡。
- **轻提示**：右下角胶囊形 toast，浅色底，`2.6` 秒淡出；错误态为红底白字。
- **降级**：`prefers-reduced-motion` 下关闭过渡与光斑动画。

## 4. 两个界面的视觉一致性

同一套语言，不同密度：

| 维度 | popup | 管理页 |
| --- | --- | --- |
| 底色 | `#3c3c3c` | `#2b2b2b` / 侧边栏 `#232323` |
| 控件高度 | `37px` | `44px` |
| 圆角 | `8px` | `10px` |
| 分隔 | `1px solid #fff` 描边 | `#3a3a3a` 细分隔线 |
| 强调 | 白底黑字 | `primary` 浅底深字 |
| 特效 | 光斑 + 选项波纹 | 光斑 + 分段波纹 + 折叠过渡 |

两者都只用一种强调色（白 / 浅灰），不引入第二种品牌色——氛围类插件的界面本身不该抢画面。
