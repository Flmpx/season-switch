# 弹窗设置界面设计（Season Switch）

> 本文件描述 Season Switch 设置**弹窗界面**的最终设计（视觉、导航、交互、模块划分）。
> 渲染/氛围相关的引擎设计见 [`design.md`](./design.md)，美术观感见 [`art.md`](./art.md)。

## 1. 总体形态

点击插件图标，弹出一个 **popup 弹窗**（非独立标签页）。弹窗只承载设置界面，采用 **iOS 式导航栈**：首屏是几个主选项，点选项后新页面从右侧滑入、旧页面向左推出；逐层下钻，每层顶部有「返回」。

- 弹窗宽度固定 `340px`，高度**由当前页面内容自适应**（配合 `height` 过渡动画），上限 `600px`，超出则页面内部滚动。
- 背景 `#3c3c3c`（中深灰），文字 `#e8e8e8`。

## 2. 视觉主题

| 项目 | 取值 | 说明 |
| --- | --- | --- |
| 弹窗背景 | `#3c3c3c` | 中深灰底 |
| 正文文字 | `#e8e8e8` | 浅灰白 |
| 选项按钮边框 | `1px solid #ffffff` | 白边框 |
| 选中态 | 白底 `#ffffff` + 黑字 `#161616` | 点击后即刻生效 |
| hover 光斑 | `rgba(255,255,255,0.06~0.18)` 径向渐变 | 光标跟随的淡白柔光 |
| 选项按钮尺寸 | 高 `37px`、左右留白 `20px`、字 `14px` | 与历史设定一致 |

## 3. 导航结构（iOS 式导航栈）

每个页面绝对定位叠放，按"其在栈中下标相对当前栈顶的偏移"各自做 `translateX` 横向位移：

- **进入（push）**：新页先瞬时置于右侧屏外，再统一设目标位移 → 旧页 `0→-100%` 左滑出、新页 `100%→0` 右滑入。
- **返回（pop）**：当前页 `0→+100%` **向右滑出**，下层页 `-100%→0` 从左滑入。
- 与层级深度无关，任意多级下钻/回退都正确。

**页头**：标题居中，左上角「返回」按钮（无 `‹` 符号，字号 `14px` 略小于标题 `15px`）。

**页面层级（最终）**：

```
主页（4 个主选项，右侧带 ›）
├─ 季节      春/夏/秋/冬/自定义/跟随系统 + 自定义月份滑块
├─ 时间      清晨/上午/中午/下午/傍晚/晚上/深夜/自定义/跟随系统 + 自定义小时滑块
├─ 显示程度  朦朦/浅/中/深/自定义 + 自定义百分比滑块
└─ 粒子（元素列表，同构于主页）
   └─ 单个元素（按类型）
      ├─ 速度   慢/中/快/自定义
      ├─ 大小   小/中/大/自定义
      └─ 数目   微量/少量/中等/大量/自定义  （星光隐藏"速度"项，数目含义为午夜峰值颗数）
```

> 自定义类选项被选中时，对应滑块行展开；切换选项会改变内容高度，弹窗高度随之平滑过渡。

## 4. 交互特效

由 `popup/effects.ts` 以事件委托挂在根节点上统一处理，不侵入各页面模块。

- **hover 光斑**：`mousemove` 时把光标相对元素左上角的坐标写入 `--mx`/`--my`，CSS 用 `radial-gradient` 在该处画柔光，仅 `:hover` 时可见、跟随光标。作用于 `.row` / `.option-btn` / `.back`。
- **点击波纹**：仅作用于 `.option-btn`（点了**不翻页**的选项按钮）。点击后按钮**立即**白底黑字，同时从点击点生成一个灰色圆（`rgba(0,0,0,0.35)`，比白底暗、比界面底色亮），按按钮对角线尺寸放大扩散并淡出。`.option-btn` 通过 `isolation: isolate` 建立层叠上下文，使灰色波纹落于白底之上、文字之下。
- **切换行 / 返回**：主页行、粒子页元素行、返回按钮**不挂波纹**（一点即滑走新页面，波纹看不到）。

## 5. 模块划分（模块化）

每个页面独立成文件、各自渲染 + 绑定，不强行抽公共函数（即便代码重复）。文件清单：

| 文件 | 职责 |
| --- | --- |
| `popup/index.html` | 弹窗入口：`.nav-stack > .pages#pages` 容器，页面由 JS 挂载 |
| `popup/main.ts` | 入口：加载设置、渲染主页、启用交互特效 |
| `popup/nav.ts` | 导航栈：`initNav` / `pushPage` / `popPage` / `refreshHeight` |
| `popup/effects.ts` | 交互特效：hover 光斑 + 点击灰色波纹（事件委托） |
| `popup/style.css` | 全部样式（暗色主题、导航栈、选项、波纹等） |
| `popup/pages/main.ts` | 主页：4 个主选项入口 |
| `popup/pages/season.ts` | 季节设置页 |
| `popup/pages/time.ts` | 时间设置页 |
| `popup/pages/display.ts` | 显示程度设置页 |
| `popup/pages/particle.ts` | 粒子元素列表（同构于主页） |
| `popup/pages/element.ts` | 单个粒子元素的详细设置（速度/大小/数目） |

各页面只从 `lib/settings` 读取/写入配置、从 `nav` 取导航能力、从 `envir/particle` 只读元素元数据，互不耦合。
