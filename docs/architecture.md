# 这个插件是怎么跑起来的（大白话版）

> 面向非开发者的通俗说明，尽量少用术语。想要精确的技术细节，见 [`design.md`](./design.md) / [`page.md`](./page.md) / [`art.md`](./art.md)。

## 一句话

你在用别的网站时，插件往页面最上层盖了三层东西：一层淡淡的季节颜色、一层调明暗的遮罩、一层会动的粒子画布。弹窗里你调的那些数字，就是在调这三层各自的强度。

## 打开一个网页时，它按顺序做了什么

1. **点名**：把"插件自带的元素"、"你自己做的元素"、"你对自带元素做的修改"合成一份最终名单（代码里叫注册表 `registry`）。
2. **读设置**：从浏览器本地存储里翻出你上次设的季节、时间、显示程度、每个元素的速度/大小/数目。
3. **先备图**：如果名单里有图片粒子，先把图片读进内存。读不出来就先跳过（比如元素刚存、图片还没存完），下次再试。
4. **盖三层**，然后开始每秒约 60 次的循环。
5. **每帧三件事**：该不该生成新粒子、星星数量对不对、每个粒子挪一点并画一下。

## 三处"仓库"分别放什么

| 仓库 | 放什么 | 谁在写 |
| --- | --- | --- |
| `settings` | 季节、时间、显示程度、每个元素的速度/大小/数目 | 弹窗、管理页的详情页 |
| `userLibrary` | 你自己做的元素 + 对内置元素的修改 | 管理页（新建 / 详情 / 导入） |
| `asset:<id>` | 上传的图片（存成文本形式，按内容去重） | 管理页上传图片时 |

为什么分开？因为它们的"更新频率"和"归属"不一样：设置你天天调，元素库你偶尔做，图片扔进去就不动了。分开放之后，改一个数字不用重写整个元素库。

## 几个你可能好奇的问题

**为什么只有叶子会随季节变色？**
叶子配了春/夏/秋三套色板，生成时按当前季节的权重随机挑颜色。别的元素没有色板，所以"季节"对它们只起一个作用：决定这个季节出不出现。

**为什么内置元素不能删？**
那是插件自带的出厂内容，删了谁也造不回来。所以允许改、但删不掉，并且给一个"恢复默认"。你对内置元素的修改单独记在 `overrides` 里，原始数据没被覆盖——这也是能一键恢复的原因。

**为什么改完立刻生效，没有保存按钮？**
因为写存储很快，改错了还能改回来，多一个"保存"只会让人忘记点。唯一的例外是"新建粒子"：那是草稿，点保存才进列表，免得半成品堆一地。

**为什么导入 SVG 不干脆把路径重写一遍？**
重写要处理弧线、旋转、缩放，很容易算歪。现在是"路径原封不动 + 附带一个变形系数（矩阵）"，显示时再把系数套上去，弧线也能精确还原。顺带说，这是因为当前环境装不了 `svgpath` 那类现成库，所以选了另一条路。

**为什么管理页要单独开一个网页？**
弹窗只有 340 像素宽，塞不下一张完整表单（名称、图片、十几项参数、实时预览）。你之前也说过"点开是一个新建的网页"。

**为什么点「＋」有时不新开标签页？**
它会先找有没有已经打开的管理页，有就跳过去并切到"新建粒子"，免得开一堆重复的。

## 出问题先看哪儿

| 现象 | 先查 |
| --- | --- |
| 页面上什么都没有 | 弹窗里粒子数目是不是 0；当前季节这个元素参不参与 |
| 只有图片粒子不显示 | 图片是否超过 512KB；换环境后图片资产没有跟着 JSON 走（导出不含图片） |
| 星星数量不对 | 星光是"午夜峰值 + 25% 保底"，19 点刚入夜本来就只有四分之一 |
| 管理页改了没生效 | 正常情况下会立刻生效（页面不用刷新）；再看是否被时段/季节限制挡住 |

## 想改点什么，该动哪个文件

| 想改的东西 | 去哪儿改 |
| --- | --- |
| 内置元素的形状/颜色/动效数值 | `entrypoints/envir/particle/elements.json` |
| 再增加一个内置元素 | 同上，加一条描述（不用改代码） |
| 季节色调、亮度公式 | `entrypoints/envir/intensity/`、`entrypoints/envir/light/` |
| 弹窗界面 | `entrypoints/popup/` |
| 管理页界面 | `entrypoints/manager/` |
| 存储格式、元素库读写 | `lib/settings.ts`、`lib/element-store.ts` |

## 名词对照

| 代码里的词 | 说人话 |
| --- | --- |
| 描述符 `ElementDescriptor` | 一个元素的身份证：叫什么、长什么样、怎么动、什么季节出现 |
| 注册表 `registry` | 把"内置 + 你自己做的 + 你的修改"合成最终名单 |
| 生效值 | 元素自带的默认值，和你在弹窗里设的值，合并后的结果 |
| 覆盖 `override` | 你对内置元素做的修改，只记录改了的那几项 |
| 资产 `asset` | 你上传的图片，存起来供图片粒子使用 |
